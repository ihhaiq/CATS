# دليل أصول القطط والحالات

هذا الملف هو المرجع الفني لإضافة صور القطط في Catibot.  
لا نحذف أي سلالة أو كود أو أصل قديم عند إضافة صور جديدة.

## مصدر الحقيقة

الأصول الرسمية تكون داخل المستودع هنا:

```text
bot/assets/cats/<breed>/<age_stage>/<state>.png
```

مثال:

```text
bot/assets/cats/siamese/adult/play.png
```

ملفات الصور المحلية هي مصدر الحقيقة. أما Telegram `file_id` فهو cache أو fallback أو override إداري فقط.

## السلالات

السلالات المعرفة حاليًا في النظام:

- `orange_tabby`
- `black`
- `siamese`
- `british_shorthair_grey`
- `calico`
- `white`

السلالات غير الموجودة صورها لا تُحذف ولا يتوقف كودها. هي معطلة مؤقتًا من واجهة المستخدم بسبب العدد الكبير من الصور المطلوبة.

حاليًا:

- التبنّي الجديد يستخدم `siamese`.
- القطة القديمة تحتفظ بسلالتها.
- صور السلالة القديمة تستخدم fallback إذا لم يتوفر الأصل المطلوب.

## مراحل العمر

- `kitten`: من 0 إلى 6 أيام
- `junior`: من 7 إلى 20 يومًا
- `adult`: من 21 إلى 89 يومًا
- `senior`: من 90 يومًا فما فوق

إذا لم توجد صورة لمرحلة العمر المطلوبة، يبحث النظام بالترتيب عن:

1. نفس السلالة ونفس العمر والحالة.
2. نفس السلالة بعمر `adult`.
3. المسار legacy للسلالة.
4. الصورة العامة للحالة.
5. Telegram cache أو override إن وجد.

## الحالات الرسمية

| الحالة | الملف | معنى الصورة |
|---|---|---|
| عادية | `idle.png` | القطة هادئة وتنظر للمستخدم |
| سعيدة | `happy.png` | القطة فرحانة وملامحها لطيفة |
| جائعة | `hungry.png` | القطة جائعة وتنتظر الطعام |
| إطعام | `feed.png` | القطة تأكل أو بجانب وعاء الطعام |
| لعب | `play.png` | القطة تلعب بطاقة وحركة واضحة |
| نزهة | `walk.png` | القطة مستعدة للنزهة أو تمشي |
| تحدث | `talk.png` | القطة متفاعلة مع المستخدم |
| نوم | `sleep.png` | القطة نائمة ومرتاحة |
| غاضبة/رافضة | `angry.png` | القطة رافضة التفاعل أو الاستيقاظ |
| مريضة | `sick.png` | القطة متعبة أو تحتاج عناية |

## وضعية الاستلقاء

الاستلقاء موجود كفعل داخل اللعبة باسم `relax`، لكنه ليس حالة صورة مستقلة داخل قائمة الأصول الحالية. لذلك يستخدم النظام صورة `idle.png` كـfallback حاليًا.

عند توفير الصورة مستقبلًا، يكون المسار المقترح:

```text
bot/assets/cats/<breed>/<age_stage>/relax.png
```

ولا نضيفها إلى runtime إلا بعد توفير الأصول واختبار resolver.

## الوضع الحالي لـSiamese

الموجود حاليًا:

```text
bot/assets/cats/siamese/adult/idle.png
bot/assets/cats/siamese/adult/hungry.png
bot/assets/cats/siamese/adult/sleep.png
bot/assets/cats/siamese/adult/angry.png
```

الناقص حاليًا للبالغ:

```text
happy.png
feed.png
play.png
walk.png
talk.png
sick.png
```

ولا توجد حاليًا صورة مخصصة لـ`play` أو وضعية `relax`. لذلك قد تظهر صورة fallback أو رسالة عدم توفر الصورة، حسب مصدر الوسائط الموجود.

## أسلوب الرسم

كل صور السلالة الواحدة يجب أن تحافظ على:

- نفس شكل القطة وهوية الوجه والعلامات واللون.
- نفس النسب وحجم الشخصية داخل اللوحة.
- رسم ثنائي الأبعاد شبه واقعي ولطيف، وليس أسلوبًا كرتونيًا مختلفًا.
- خلفية شفافة بصيغة PNG.
- القطة في الوسط مع ترك هامش آمن من جميع الجهات.
- عدم قص الأذنين أو الذيل أو الأرجل.
- عدم إضافة نصوص أو شعارات أو watermark داخل الصورة.
- تغيير الوضعية والتعبير فقط، مع بقاء السلالة واضحة.
- تعبيرات سعيدة أو لطيفة عند الحالات العادية؛ الغضب يقتصر على حالة الرفض أو الانزعاج.
- إضاءة وألوان متقاربة بين جميع الحالات.

## قواعد الصور حسب الحالة

### `idle.png`

قطة واقفة أو جالسة بهدوء، تنظر للأمام، تعبير طبيعي ولطيف.

### `happy.png`

تعبير فرح واضح، أذنان مرفوعتان، ذيل مرتفع أو حركة لطيفة.

### `hungry.png`

تعبير جوع وانتظار، ويمكن وضع وعاء فارغ بجانبها. لا تكون غاضبة.

### `feed.png`

القطة تأكل من وعاء أو تتفاعل مع الطعام. يجب أن تكون الصورة مختلفة بوضوح عن `hungry.png`.

### `play.png`

القطة في حركة لعب واضحة: كرة أو لعبة بسيطة، وضعية قفز أو مطاردة، مع الحفاظ على وضوح الوجه.

### `walk.png`

القطة تمشي أو تستعد للخروج، وضعية جسم مائلة للحركة ويمكن إضافة أثر بسيط للنشاط دون خلفية كاملة.

### `talk.png`

القطة متوجهة للمستخدم، فمها مفتوح قليلًا أو تعبيرها يوحي بالتفاعل والكلام.

### `sleep.png`

القطة ملتفة أو مستلقية براحة، عيون مغلقة، تعبير هادئ، دون ملامح غضب.

### `angry.png`

القطة رافضة أو منزعجة، لكن بدون مبالغة أو شكل مخيف. هذه الحالة تستخدم عند الرفض أو بعض الحالات السلبية.

### `sick.png`

القطة متعبة، جسمها منخفض قليلًا وتعبيرها ضعيف. لا تستخدم ملامح موت أو إصابة قاسية.

## قبل إضافة أي صورة

- تأكد من اسم الملف lowercase وبالاسم الموجود في `CAT_STATES`.
- ضع الصورة في مسار السلالة والعمر الصحيح.
- لا تستبدل صورة موجودة إلا إذا كان البديل يحافظ على نفس الهوية والأسلوب.
- اختبر الحالة عبر `/dev_media_test` أو بطاقة القطة.
- تحقق من أن الصورة لا تنقص أطراف القطة عند عرضها داخل Rich Message.
- لا تسجل `file_id` يدويًا بدل إضافة الملف المحلي.
